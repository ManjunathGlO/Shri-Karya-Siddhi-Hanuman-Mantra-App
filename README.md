# Shri Karya Siddhi Anjaneya – 108 Mantra Jaap 🙏🚩

A devotional digital **16-day Mantra Jaap application** created for **Shri Karya Siddhi Anjaneya Temple, Bengaluru**.

The app allows devotees to chant the prescribed Hanuman mantra **108 times each day for 16 days**, completing a total of **1,728 mantra repetitions**.

> **Tvamasmin kāryaniyōgē**
> **pramāṇaṃ harisattama**
> **hanuman! yatnamāsthāya**
> **duḥkhakṣaya karo bhava**

### Features

* 🙏 108 mantra repetitions per day
* 🗓️ 16-day spiritual sankalp
* 📿 1,728 total mantra repetitions
* 🔊 Mantra audio playback
* 📊 Daily and overall progress tracking
* 🔄 Reset today's chanting count
* 💾 Progress automatically saved in the browser
* 🚩 Day-by-day completion tracking
* 📱 Responsive design for mobile and desktop
* 🌐 Built with HTML, CSS and JavaScript

### Technology

* HTML5
* CSS3
* JavaScript
* LocalStorage
* HTML5 Audio API

### Purpose

The purpose of this project is to provide devotees with a simple digital way to participate in the **108 mantra jaap for 16 days**, while maintaining their daily and overall chanting progress.
